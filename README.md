# Lenon The Barber

Site profissional para barbearia desenvolvido como projeto de portfólio.
Foco em conversão de clientes, design premium e performance mobile.

## Tecnologias

- HTML5 semântico
- CSS3 com Custom Properties (Design Tokens)
- JavaScript puro — sem frameworks
- Deploy: Netlify

## Funcionalidades

- Design responsivo (mobile-first)
- Scroll reveal com IntersectionObserver
- Botão WhatsApp fixo com mensagens contextuais por serviço
- Portfólio com fotos reais do cliente
- Tabela de preços completa
- Meta tags para SEO e Open Graph
- Acessibilidade (aria-labels, semântica, prefers-reduced-motion)

## Como rodar localmente

1. Clone o repositório
2. Abra a pasta no VS Code
3. Instale a extensão Live Server
4. Clique em "Go Live" no canto inferior direito

## Deploy

Netlify — publish directory: `src`
